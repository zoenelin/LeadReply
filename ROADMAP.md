# LeadReply Roadmap

## Active Build Order

The original eight-item CRM foundation is now implemented. The current near-launch work is provider setup, production deployment, real-client onboarding, and safety testing.

1. Lead Center
   - Add a leads page.
   - Let users add leads manually.
   - Track source, status, estimated value, captured value, follow-up date, and notes.

2. Lead Detail View
   - Add a detail page for each lead.
   - Let users update lead status, values, notes, and follow-up details.

3. Better Analytics
   - Add source, status, and date filters.
   - Split reporting into open lead value, captured revenue, lost opportunity, and recovered revenue.

4. Follow-Up Tasks
   - Show today's follow-ups on the dashboard.
   - Use lead follow-up dates to drive a simple task list.

5. Review Request System
   - Prompt for review requests after a lead is marked captured.
   - Track review request status before connecting real Google review automation.

6. Automation Settings
   - Add setup screens for phone, booking, reviews, SEO, and marketing.
   - Collect enough information for later integrations.

7. Billing Plans
   - Add a billing/settings page.
   - Connect Stripe checkout once production price IDs are added.
   - Show plan capabilities clearly.

8. Mobile Polish And PWA
   - Add mobile-friendly navigation.
   - Keep forms, cards, and dashboards easy to use on a phone.
